# 🛒 NovaCart - Premium Shopping Website

## 📌 Overview

NovaCart is a modern e-commerce web application built using HTML, CSS, and JavaScript. It provides a clean shopping experience with product browsing, category filtering, product search, shopping cart management, and user authentication pages.

The project is designed to demonstrate frontend web development concepts such as DOM manipulation, responsive design, filtering, searching, pagination, and cart functionality.

---

## 🚀 Features

### 🏪 Product Catalog

* Display multiple products in a responsive grid layout
* Product image, name, price, rating, and description
* Pagination support

### 🔍 Search Functionality

* Search products by name
* Real-time filtering while typing

### 📂 Category Filtering

* Filter products by category
* Dynamic product updates

### 💰 Sorting Options

* Featured Products
* Price: Low to High
* Price: High to Low

### 🛒 Shopping Cart

* Add products to cart
* Increase or decrease quantity
* Remove individual products
* Clear entire cart
* Automatic subtotal calculation
* Shipping charge calculation
* Total price calculation

### 👤 User Authentication Pages

* Login Page
* Registration Page

### 📱 Responsive Design

* Mobile-friendly interface
* Modern UI design
* Interactive navigation bar

## 🎯 How It Works

### Product Display

* Products are stored in a JavaScript array.
* Products are rendered dynamically into the product grid.

### Search

* User enters text in the search box.
* Matching products are displayed instantly.

### Category Filter

* User selects a category.
* Products belonging to that category are shown.

### Cart Management

* Add products using the "Add to Cart" button.
* Update quantity using + and - controls.
* Remove products individually.
* Clear the entire cart.

### Checkout

* Checkout button becomes active when cart contains items.
* Redirects users to the login page before checkout.
